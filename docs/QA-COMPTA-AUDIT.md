## 1) الخريطة المعمارية (بعد إعادة البناء)

```
[Compta] ──journal──▶ buildJournalEntries (خالص، مُختبر)
              │         CANCELLED مستبعدة • PROV مميزة • 530/512 مفصولة • طابع مذكرة
         ──period──▶ اليوم/الشهر/الكل مربوط بالدفتر + بطاقتي التدفق (هامش/CA)
         ──snapshots──▶ مخزون/أرصدة/خزينة تراكمية (مُسماة صراحة)
         ──CSV──▶ journalToCsv (BOM، Excel-FR) ──print──▶ #printable-compta (A4)
         ──treasury──▶ مبيعات + تحصيل(أصل+طابع) − موردين − استلامات − **مصاريف** (C1)
         ──CAMV──▶ تكلفة **لحظة البيع** (unit_cost_ht) ثم PMP الحي ثم احتياطي (C2)
```
