# ADR-040-MKT: نطاق v1.5.0 المدمج + الاستثناء الموثق (إسقاط شرط الأرقام)

- **Status:** ACCEPTED — بقرار المالك الصريح 2026-11-05
- **النطاق:** v1.5.0 = استقرار 1.4.10 كاملاً (T8b، صفر تحذيرات، الطقم) + الإرجاع (مهلة 7 أيام، شخصان فوق 5000 دج). لا نشر لـ 1.4.10 منفردة؛ المثبت المبني سابقاً (5.19 MiB) أصبح أرشيفياً ويُعاد البناء لـ 1.5.0.
- **الاستثناء (A3):** الأرقام الثلاثة (FACT/Z/التغيير الإجباري) **ليست شرطاً** للنشر — قرار المالك بعد شهادته بكفاءة 1.4.10 ميدانياً ("تعمل بكفاءة").
- **المسؤولية الهندسية (موقعة):** أنا أتحمل كامل أثر هذا الاستثناء. التخفيف المتبقي:
  1. كل البوابات الآلية خضراء (tsc + 392 + cargo 31 + صفر تحذيرات + build).
  2. شهادة المالك الميدانية تحل محل الأرقام كدليل دخول.
  3. سيناريو الإرجاع الحديدي (RUNBOOK-v1.5.0) يُعاد فيه التحقق من تسلسل FACT/Z ضمنياً — أي انكسار سيظهر هناك قبل النشر.
- **القاعدة:** هذا استثناء لمرة واحدة باسم المالك، لا سابقة — §7 يبقى ملزماً لما بعده.
