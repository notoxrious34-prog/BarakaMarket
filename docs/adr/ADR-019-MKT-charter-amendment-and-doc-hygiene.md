# ADR-019-MKT: Charter Amendment — Binary Artwork Exception, Baseline Annotation, Doc Hygiene

**Status:** Accepted · **Date:** 2026-11-01 · **Release:** v1.0.1
**Amends:** `CHARTER-v2.0-MKT.md` Laws §6, Baseline §23–27 (re-ratified herein per charter rule).

## Context
Architecture review of `docs/architecture/` (4 docs, verified against disk:
195/195 tests green, 22 schema tables, `com.barakamarket.pos`, tags
`v2.0.0-mkt`/`v1.0.1-mkt`) found the corpus truthful with six minor findings.
This ADR disposes of all six so the charter stays normative, not aspirational.

## Decision
1. **Law 6 reworded** (was: *"no binary assets"* — unenforceable; the repo
   legitimately ships brand PNG/ICO artwork):
   **Hardware autonomy — no binary RUNTIME dependencies and no opaque data
   blobs; deterministic ESC/POS; synthesized WebAudio feedback; brand artwork
   (PNG/ICO) excepted and generated by `scripts/make-brand-assets.py`.**
2. **Baseline annotated:** `58/58 tests` is frozen as the TASK-AUD-001 figure
   at `fd23dd7`/tag `v1.0.0`; current gate is `195/195` (`npm test`).
3. **ADR-018 relocated** `docs/architecture/` → `docs/adr/` (uniform register).
4. **MASTER §7 installer path** corrected to `$CARGO_TARGET_DIR/...` with the
   shop-machine note (D: convention).
5. **D3 (HWID display) verified resolved:** `LicenseManagerView` computes the
   HWID live via `computeHwid()` (canonical 4-group `BM-XXXX-XXXX-XXXX-XXXX`);
   no legacy 3-group string remains anywhere in `src/`, `scripts/`, `db/`.
6. **Build-environment paragraph** added to the Blueprint (§7): C: full,
   `CARGO_HOME`/`CARGO_TARGET_DIR` on D:, WebView2 prerequisite.

## Consequences
- Charter Law 6 is enforceable again: CI-relevant check = no new binary
  extensions outside `public/brand/**` + `src-tauri/icons/**`.
- No fiscal, licensing, schema, or engine file touched by this ADR
  (docs + one relocated file only).

## Invariants preserved
Fiscal monism, atomic pad-6 sequences, Art.136 timbre, zero-cloud,
zero-mouse, air-gapped licensing, single-click offline deploy — none altered.
