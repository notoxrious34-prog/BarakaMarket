# ADR-042-MKT — نطاق v1.5.1: شحن المنجز (UX + Retours + F3/F6)، وترحيل B2-6 لخطة مستقلة

- **التاريخ**: 2026-11-07 — **الحالة**: معتمد من المالك (قرار صريح 2026-11-07: شحن الآن بما اكتمل + تأجيل B2-6 بقرار موثق).
- **السياق**: ADR-041 أجّل B2-6 (الجلسات الحية + زر الإسقاط) إلى v1.5.1. عند مراجعة النطاق قبل الإصدار، تبيّن أن المسوغ المعماري ما زال قائماً حرفياً: لا بنية حضور شبكي في معمارية المحل-الواحد، واشتقاق الحضور من الـ audit إشارة كاذبة، والزر الوهمي مخالف لـ Zero-Trust.

## القرار
شحن v1.5.1 بالنطاق المنجز والمثبت حياً:
1. UX-1.5.1 (رخصة مؤسسية بلا سعر + هوية Baraka DEV + حذف الميزان العلوي + توحيد الثيم فاتح/داكن + خطة موثقة).
2. مكتب الإرجاع المُعاد تصميمه + البحث المتسامح عن الفاتورة (exact → short → suffix، TS + Rust + اختبارات).
3. إصلاحا الصندوق F3 (استهداف آخر سطر + إصلاح سرقة التركيز) وF6 (مكتب الميزان 1·2·3) — مثبتة حياً داكن/فاتح.
- B2-6 **لا يُبنى داخل v1.5.1** ولا يُنفذ شكلياً؛ يُرحَّل لخطة مستقلة تُفتح عندما تُعتمد معمارية الحضور (heartbeat + registry + أقنية تعدد أطراف). هذا القرار نهائي لهذه النسخة وليس تأجيلاً مفتوحاً بلا مسوغ.

## ما لا يتغير
- ضوابط الطرفية الواحدة (قفل يدوي + تغيير إجباري + تدوير + انتهاء مؤقت + مهلة خمول 15 دقيقة) تبقى هي الضابط الكافي للمعمارية الحالية.
- يُمنع أي تنفيذ شكلي للحضور (مهلة ثابتة/تخمين) — محظور دستورياً (لا ترقيع، لا إشارات كاذبة).
