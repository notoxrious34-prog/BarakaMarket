# ADR-041-MKT — نطاق v1.5.0 النهائي: B1 + B2(1-5)، وتأجيل B2-6 لـ v1.5.1

- **التاريخ**: 2026-11-07 — **الحالة**: معتمد تنفيذياً (بانتظار مراجعة المالك عند الإصدار).
- **السياق**: ADR-040 دمج T8b + RETURNS + Utilisateurs في نسخة واحدة (v1.5.0). خطة B2 تعدّ 6 بنود؛ أُنجزت 1-5 ببواباتها (406/406 + 34/34 + إثباتات Edge). البند 6 — **الجلسات الحية + زر إسقاط الجلسة** — لم يُنفذ.

## القرار
شحن v1.5.0 بالنطاق المنجز (B1 + B2/1-5) وتأجيل B2-6 إلى v1.5.1.

## المسوغ المعماري
1. **الحضور الحقيقي يتطلب بنية غير موجودة**: «قائمة الداخلين الآن» عبر الأجهزة تستلزم سجل حضور شبكي (heartbeat + registry) — التطبيق الحالي محل-واحد/طرفية-واحدة بخادم loopback محلي؛ لا توجد أقنية تعدد أطراف يُبنى عليها الحضور.
2. **اشتقاق الحضور من الـ audit غير أمين**: `login.ok` بلا `logout` لا يعني جلسة حية (انقطاع كهرباء، إغلاق قسري) — قائمة كاذبة أسوأ أمنياً من غياب القائمة.
3. **زر الإسقاط بلا حضور موثوق = زر وهمي**: إسقاط جلسة غير مؤكدة الوجود يخلق إحساساً زائفاً بالسيطرة ويخالف Zero-Trust (لا إشارات كاذبة).
4. **لا ترقيع داخل الإصدار**: تنفيذ شكلي (مهلة ثابتة/تخمين) كان سيُدخل كوداً غير قابل للاختبار بصدق — محظور دستورياً.

## ما لا يتغير
- الجلسة المحلية القائمة (قفل يدوي + تغيير إجباري + تدوير + انتهاء مؤقت) تبقى هي ضابط الطرفية الواحدة — كافية للمعمارية الحالية.
- B2-6 يُعاد فتحه بخطة مستقلة عندما تُعتمد معمارية الحضور (v1.5.1).

## البوابات المنجزة لـ v1.5.0
`tsc` + `test:all 406/406` + `cargo test 34/34` صفر تحذيرات + `npm run build` + `cargo build` صفر تحذيرات + حديدية حية IRON PASS (FACT-2026-000001 → RET-2026-000001 → Z-2026-000001) + إثباتات Edge لكل بند (B1 + B2/1-5).
