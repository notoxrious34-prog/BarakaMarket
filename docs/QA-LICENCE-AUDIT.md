# التدقيق المؤسسي — صفحة الترخيص (Licence) + إعادة البناء — 2026-11-04

> معيار Microsoft: كل كلمة في الكود مقروءة، كل عملية مُتتبعة من الزر حتى القرص.
> النطاق: `LicenseManagerView` (230 سطر) + `licensing` (Ed25519/HWID) +
> `license-store` (ثبات + مرآة SQLite) + `activation-desk` (أداة الموظف) +
> بوابة `isTrialExpired` في POS + `license-verify` (جديدة).

## 1) الخريطة المعمارية (بعد إعادة البناء)

```
[Licence] ──hwid──▶ seed ثابت + بصمة المتصفح → BM-XXXX…
     │        ├──activate──▶ validateLicense (Ed25519 على STORE||HWID) → تخزين + مرآة SQLite
     │        ├──boot─────▶ assessStoredLicense: توقيع؟ جهاز؟ (L1)
     │        ├──gate─────▶ مزور ⇒ منتهي (POS مقفل) • منحرف ⇒ تحذير فقط (L-drift)
     │        └──trial───▶ 50 بيع / 14 يوم — كلاهما معاً للإقفال
```

## 3) أسئلة للمالك (نقاط سياسة — لا تخمين)
1. **قفل الانجراف؟** مفتاح سليم على جهاز مختلف: تحذير فقط (الحالي) أم إقفال POS؟
